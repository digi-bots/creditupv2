One-time setup (Setup guide)

To turn on online payment, add these values in Vercel → Project → Settings → Environment Variables, then Redeploy. They are secret, so they are never kept in this panel or in Firestore.

  1. SSLCZ_STORE_ID — the Store ID from the SSLCommerz merchant panel
  2. SSLCZ_STORE_PASSWD — the SSLCommerz Store Password (API password)
  3. SSLCZ_SANDBOX — true for testing, false for real payments
  4. FIREBASE_SERVICE_ACCOUNT — Firebase Console → Project settings → Service accounts → press Generate new private key and paste the full text of the JSON file it downloads
  5. PUBLIC_BASE_URL (optional) — for example https://creditup.online

When everything is right, a green tick and "Server is ready" show above. Then turn on the switch on the right. Test in Sandbox first.

2 · Loan send to customer (automatic)After a loan is approved, the money goes to the customer's number automatically through an API
Not connected

Sending money automatically needs each provider's own Disbursement / B2C API, such as bKash, Nagad and Rocket merchant disbursement. You get these credentials through an agreement with each provider. SSLCommerz can only receive money, not send it.

When you get API access from a provider, share its documentation and sandbox credentials and it can be added here. Until then, send loans from Manual → Loan send.
