Loan disbursementWhere you send the loan money. Each customer enters their own number in the application form.
1 · Online payment (automatic)
Users pay the fee on the SSLCommerz page (bKash, Nagad, Rocket, Visa, Mastercard, net banking). The payment is checked with SSLCommerz and the application moves to Fee Verified on its own, so no TrxID is needed. The store ID and password are kept on the server (Vercel settings), never here.
একবার সেটআপ করতে হবে (Setup once)

অনলাইন পেমেন্ট চালু করতে Vercel → Project → Settings → Environment Variables-এ নিচের ভ্যালুগুলো বসান, তারপর Redeploy করুন। এগুলো গোপন, তাই এই প্যানেলে বা Firestore-এ রাখা হয় না।

  1. SSLCZ_STORE_ID — SSLCommerz merchant panel থেকে পাওয়া Store ID
  2. SSLCZ_STORE_PASSWD — SSLCommerz-এর Store Password (API password)
  3. SSLCZ_SANDBOX — টেস্টের জন্য true, আসল পেমেন্টের জন্য false
  4. FIREBASE_SERVICE_ACCOUNT — Firebase Console → Project settings → Service accounts → Generate new private key চাপলে যে JSON ফাইল নামে, তার পুরো লেখা কপি করে বসান
  5. PUBLIC_BASE_URL (ঐচ্ছিক) — যেমন https://creditup.online

সব ঠিক থাকলে নিচের বক্সে সবুজ টিক আর "Server is ready" দেখাবে। তারপর "Show online payment to users" চালু করে Save করুন। প্রথমে Sandbox-এ টেস্ট করে নিন।
